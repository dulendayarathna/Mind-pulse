# 🧠 MindPulse — AI Study Assistant

An intelligent, interactive, and modern **AI-powered Study Workspace** built step-by-step for university students and developers to transform lecture notes into interactive flashcards and self-test quizzes.

## 📅 7-Day Build Roadmap

- [x] **Day 1:** Core App Shell, Navbar, Input Card & Prompt Chips
- [ ] **Day 2:** Animated Aurora Background & Dark/Light Mode Engine
- [ ] **Day 3:** Google Gemini AI API Integration & Settings Modal
- [ ] **Day 4:** Interactive 3D Flip Flashcards & Deck Navigation
- [ ] **Day 5:** Self-Test Quiz Engine with Live Grading & Explanations
- [ ] **Day 6:** Saved Decks Library (`localStorage` history)
